# Harness Engineering (Milestone 3)

The Harness acts as the protective wrapper around the core Agentic Loop, ensuring that the system can run in production environments without crashing due to common network, API, or formatting issues.

## 1. Retry Logic & Exponential Backoff
**Implemented in: `agent/harness.py` (`@with_retry`)**
- **What it does:** Wraps the core LLM calls (`reason`, `reflect`). If the API throws a rate limit error or the model returns an unparseable JSON string (very common), the decorator catches the error and retries.
- **Why it matters:** LLMs are non-deterministic. A single malformed output shouldn't crash the entire hours-long agentic loop.
- **Jitter:** It adds a random jitter to the delay to prevent Thundering Herd problems if multiple agents are running.

## 2. Guardrails
**Implemented in: `main.py`**
- **Infinite Loop Detection:** The orchestrator tracks the exact `plan` generated by the Reason stage. If it detects the agent trying to execute the exact same plan multiple times in a row (stuck in a loop), it breaks execution automatically.
- **Max Iterations:** Prevents runaway compute costs. If hit, it gracefully returns the `best_result` it saw and marks the status as `PARTIAL`.
- **Token Budget:** Tracks cumulative tokens extracted from `response.usage_metadata`. Warns when the budget is exceeded.

## 3. Fallbacks
- **Memory Read Failure:** If ChromaDB goes down or the read fails, the loop doesn't crash. It catches the exception, logs a warning, and proceeds with an empty memory dictionary.
- **Tool Failure:** `act` wraps tool execution in a `try/except`. If it fails, it returns `{"status": "error"}` to the Reflect stage instead of crashing Python. Reflect can then dock the score and tell Reason to try something else.

## 4. Observability (Structured Logging)
**Implemented in: `agent/logger.py`**
- Every cognitive step (perceive, reason, act, reflect) is recorded into a local SQLite database (`agent_logs.db`). This allows developers to query exact inputs, outputs, latencies, and errors across hundreds of iterations.
